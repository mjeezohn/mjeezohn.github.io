# MjeeZohn Studio

Official music studio website: https://mjeezohn.github.io/

YouTube channel: https://www.youtube.com/@mjeezohn

This public repository hosts the browser-delivered website and its public YouTube catalogue.
The development source, YouTube synchronization script, and publishing pipeline are maintained
separately in a private repository. The public site is deployed using GitHub Pages.

All files served to a visitor, including HTML, CSS, JavaScript, imagery, and video catalogue
metadata, are intentionally public. Do not put credentials or private data in this repository.
